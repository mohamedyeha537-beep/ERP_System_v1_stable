الصق هذا الملف كاملاً في شات Cursor داخل مشروعك على الـ VPS، ونفّذ البنود بالترتيب:

===============================================================
المهمة: إكمال ربط "وكيل الدعم الفني" (Claude API) بموقع أكاديمية مهارات
===============================================================
الوضع الحالي:
- الموقع منشور على VPS خاص بي.
- نافذة الشات في الموقع موجودة لكنها تعرض حاليًا ردودًا ثابتة/تجريبية وليست متصلة
  بأي سيرفر خلفي حقيقي.
- لدي حساب واتساب مربوط بخدمة TextMeBot.
- لدي مفتاح Anthropic API (ANTHROPIC_API_KEY) ومفتاح TextMeBot (TEXTMEBOT_APIKEY)
  سأضعهما كمتغيرات بيئة (environment variables)، لا تكتبهما مباشرة في الكود.

المطلوب تنفيذه بالضبط:

---------------------------------------------------------------
1) إنشاء السيرفر الخلفي (Backend)
---------------------------------------------------------------
أنشئ مجلد جديد باسم maharat-bot بجانب مشروع الموقع الحالي، وبداخله:

أ) ملف package.json يحتوي التبعيات التالية:
   express, cors, @anthropic-ai/sdk

ب) ملف server.js يحتوي على:

- تحميل متغيرات البيئة: ANTHROPIC_API_KEY و TEXTMEBOT_APIKEY
- استخدام مكتبة @anthropic-ai/sdk للاتصال بـ Claude
- متغير SYSTEM_PROMPT بالمحتوى التالي بالضبط (اتركه كما هو، لا تختصره):

  """
  أنت "وكيل الدعم الفني" الرسمي لأكاديمية مهارات فكرية للتدريب والاستشارات
  (maharat-academy.ly).

  دورك:
  - الرد على استفسارات الزوار والمتدربين عبر الموقع والواتساب.
  - مساعدتهم في: الدورات المتاحة، التسجيل، الدفع، المشاكل التقنية في الموقع
    (تسجيل الدخول، الوصول للدورة بعد الشراء، مشاكل الفيديوهات أو الشهادات).

  قواعد صارمة:
  1. رد فقط بناءً على المعلومات المذكورة في قسم "معلومات الأكاديمية" أدناه.
     لا تخترع أسعارًا أو تواريخ أو تفاصيل غير موجودة.
  2. إن كان السؤال يحتاج معلومة غير متوفرة، قل: "سأتأكد من هذه المعلومة وأرد
     عليك، أو تواصل مع فريق الدعم مباشرة على [رقم/بريد]"، ولا تخمّن.
  3. حدد نوع الاستفسار أولاً (دورات/تسجيل/دفع/مشكلة تقنية/شكوى) ثم رد بما
     يناسبه تحديدًا، لا ردًا عامًا مكررًا.
  4. للمشاكل التقنية، اطلب تفاصيل دقيقة أولاً (نوع الجهاز/المتصفح، رسالة
     الخطأ، وقت حدوث المشكلة) قبل افتراض الحل.
  5. اجعل الردود مختصرة ومباشرة (3-5 أسطر كحد أقصى)، خصوصًا في الواتساب.
  6. لا تكرر نفس الترحيب في كل رسالة داخل نفس المحادثة، فقط في أول رسالة.
  7. عند انزعاج العميل، اعتذر بإيجاز واعرض الحل أو التصعيد لموظف بشري.
  8. لا تذكر أبدًا أنك Claude أو AI أو نموذج لغوي؛ قدّم نفسك كـ"فريق الدعم"
     أو "المساعد الرقمي لأكاديمية مهارات".

  معلومات الأكاديمية:
  [ضع هنا: الدورات المتوفرة بالاسم والسعر والمدة - طريقة التسجيل خطوة بخطوة
  - طرق الدفع المقبولة - سياسة الاسترجاع/التأجيل - روابط صفحات الدورات
  والتسجيل والدعم - رقم/بريد فريق الدعم البشري للتصعيد]
  """

  ملاحظة: اترك علامة [ضع هنا...] كما هي بالضبط في الكود بشكل واضح (مثلاً كـ
  TODO) حتى أستطيع أنا لاحقًا تعبئتها ببيانات الأكاديمية الحقيقية بسهولة.

ج) استخدم إعدادات الاستدعاء التالية عند نداء Claude:
   - model: "claude-sonnet-4-6"
   - temperature: 0.3
   - max_tokens: 500
   - أرسل system: SYSTEM_PROMPT مع كل طلب
   - احتفظ بتاريخ محادثة لكل عميل (بمفتاح مختلف لكل جلسة موقع وكل رقم واتساب)
     وأرسل آخر 20 رسالة كحد أقصى ضمن messages مع كل طلب جديد، حتى لا يفقد
     النموذج السياق.

د) أنشئ Endpoint باسم POST /api/chat يستقبل:
   { "sessionId": "...", "message": "..." }
   ويرجع:
   { "reply": "..." }

هـ) أنشئ Endpoint باسم POST /webhook/whatsapp يستقبل رسائل TextMeBot بالصيغة:
   { "type": "text", "from": "...", "message": "..." }
   ثم يستدعي Claude بنفس الطريقة، ويرسل الرد عبر رابط TextMeBot:
   https://api.textmebot.com/send.php?recipient={from}&apikey={TEXTMEBOT_APIKEY}&text={reply}&json=yes

---------------------------------------------------------------
2) تشغيل السيرفر بشكل دائم على الـ VPS
---------------------------------------------------------------
- ثبّت pm2 عالميًا: npm install -g pm2
- شغّل السيرفر: pm2 start server.js --name maharat-bot
  (تأكد من تمرير ANTHROPIC_API_KEY و TEXTMEBOT_APIKEY كمتغيرات بيئة عند التشغيل)
- احفظ العملية لتعمل تلقائيًا بعد إعادة تشغيل السيرفر: pm2 save && pm2 startup

---------------------------------------------------------------
3) ربط السيرفر بنطاق فرعي وتأمينه بـ HTTPS عبر Nginx
---------------------------------------------------------------
- تحقق هل Nginx مثبت، وإن لم يكن: sudo apt install nginx certbot python3-certbot-nginx
- أنشئ إعداد Nginx جديد يوجّه الطلبات من نطاق فرعي (سأخبرك به، افتراضيًا
  bot.maharat-academy.ly) إلى http://localhost:3000
- فعّل SSL عبر: sudo certbot --nginx -d bot.maharat-academy.ly
- تأكد أن الرابط النهائي يعمل: https://bot.maharat-academy.ly/api/chat

---------------------------------------------------------------
4) ربط نافذة الشات الحالية في الموقع بالسيرفر الحقيقي
---------------------------------------------------------------
عدّل كود نافذة الشات الموجود حاليًا (الذي يعطي ردودًا ثابتة) بحيث:
- عند إرسال الزائر رسالة، يُرسل طلب POST إلى:
  https://bot.maharat-academy.ly/api/chat
  بصيغة: { "sessionId": "معرّف فريد للزائر (وليّده وخزّنه عند فتح الصفحة
  أول مرة، مثلاً بـ crypto.randomUUID())", "message": "نص رسالة الزائر" }
- اعرض قيمة reply من رد السيرفر كرسالة جديدة من "المساعد" في نافذة الشات.
- احذف تمامًا أي رد ثابت/افتراضي كان موجودًا سابقًا في الكود.
- أضف مؤشر تحميل (typing indicator) أثناء انتظار الرد (قد يستغرق 1-3 ثواني).
- عند فشل الطلب، اعرض: "عذرًا، حدث خطأ، حاول مرة أخرى أو تواصل معنا مباشرة."
- لا تغيّر تصميم/شكل نافذة الشات، فقط استبدل منطق الإرسال/الاستقبال.

---------------------------------------------------------------
5) ربط الواتساب عبر TextMeBot
---------------------------------------------------------------
أخبرني بعد إتمام الخطوة 3 برابط bot.maharat-academy.ly النهائي، لأضعه أنا
في إعدادات Webhook داخل حساب TextMeBot يدويًا (هذا الجزء أفعله من لوحة تحكم
TextMeBot وليس من الكود).

---------------------------------------------------------------
6) الاختبار النهائي
---------------------------------------------------------------
بعد إتمام كل ما سبق:
- افتح Developer Tools (F12) > Network في المتصفح، أرسل 3 رسائل مختلفة تمامًا
  عبر شات الموقع (مثال: "مرحبا"، "كم سعر الدورة"، "عندي مشكلة تسجيل دخول")
  وتأكد أن:
  (أ) يظهر طلب فعلي لـ /api/chat في تبويب Network لكل رسالة
  (ب) كل رسالة تحصل على رد مختلف ومناسب لمحتواها، وليس نصًا مكررًا
- أرسل رسالة واتساب تجريبية بعد ربط TextMeBot وتأكد من وصول رد مناسب.

اعرض لي في النهاية:
- الكود الكامل لملف server.js
- تأكيد أن الردود أصبحت تختلف باختلاف السؤال (مع أمثلة قبل/بعد)
- رابط bot.maharat-academy.ly النهائي بعد تفعيل SSL
