AI SEO Center Specification

Restaurant & Hotel Management Platform

Project Objective

Build a complete AI SEO Center inside the existing Restaurant & Hotel Management Platform.

The platform already exists and is fully functional.

Do NOT modify existing business logic.

The SEO Center must be developed as a completely independent module that integrates with the existing platform through services and APIs.

The module should support:

- Restaurant Website
- Restaurant Online Store
- Hotel Website
- Hotel Booking Website
- Product Pages
- Room Pages
- Categories
- Blog
- Landing Pages
- Dynamic Pages

---

Architecture

Use a modular architecture.

Backend

- FastAPI
- PostgreSQL
- Redis
- n8n
- OpenAI API
- Qdrant Vector Database
- Background Workers
- REST API

Frontend

- Integrate with existing Admin Dashboard
- Responsive UI
- Dark Mode
- Charts
- Real-time Notifications

---

AI Architecture

The system must use three independent AI Agents.

Each agent must have:

- Independent Service
- Memory
- Logs
- Scheduler
- Background Tasks
- API
- Queue
- Permission System

Agents communicate through n8n workflows and share data using PostgreSQL and Qdrant.
