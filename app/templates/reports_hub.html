١ الفرق بين البيع وتكلفة البضاعة

يُسمّى محاسبياً «إجمالي الربح» أو «هامش المساهمة» — يخبرك بكفاءة سعر بيعك مقابل تكلفة الشراء فقط.
إجمالي المبيعات + {{ sales_sum.gross_revenue }} د.ل
عدد الفواتير {{ sales_sum.invoice_count }}
− المرتجعات − {{ sales_sum.returns_total }} د.ل
عدد سندات المرتجع {{ sales_sum.return_count }}
صافي المبيعات + {{ sales_sum.net_revenue }} د.ل
− تكلفة البضاعة المباعة (COGS) − {{ cogs }} د.ل
= الفرق (الربح الإجمالي) {{ gross_profit }} د.ل
الصيغة: الفرق = صافي المبيعات − تكلفة البضاعة المباعة.
المعنى: هذا ما تجنيه قبل أي مصروف أو راتب أو إيجار. إذا كان سالباً فأنت تبيع بأقل من التكلفة.

٢ صافي الربح بعد كل المصاريف

يبدأ من الفرق السابق ويطرح كل ما تنفقه: مصاريف يومية، رواتب، إيجار، اشتراكات، مستلزمات، إهلاك أصول.

عدد العمليات {{ expenses.count }}
− الرواتب والإيجار والاشتراكات (حصة الفترة) − {{ rec_period_share }} د.ل
{% if rec_breakdown %} {% for code, label, monthly, share in rec_breakdown %}
· {{ label }} ({{ monthly }} د.ل/شهر) − {{ share }} د.ل
{% endfor %} {% endif %}
− المستلزمات الاستهلاكية − {{ consumables_period }} د.ل
− إهلاك الأصول الثابتة (IAS 16) − {{ depreciation_period }} د.ل
= صافي الربح/الخسارة {{ net_profit }} د.ل
الصيغة: صافي الربح = الفرق(١) − مصاريف − رواتب وإيجار − مستلزمات − إهلاك.
ملاحظة: الرواتب والإيجار والاشتراكات قيم شهرية ثابتة — يطرح منها حصة الفترة (مثلاً ثلث الشهر يطرح ثلث المبلغ). إجمالي ثابت شهرياً = {{ rec_monthly_total }} د.ل/شهر، طول الفترة = {{ "%.1f"|format(period_days|float) }} يوم.
المعنى: هذا هو ربحك الحقيقي بعد تغطية كل التكاليف. إذا كان سالباً فأنت لم تغطّ تكاليفك بعد.
