🧠 فهم ذكي — ما الذي ينقص؟

مستوى 1 — محلي (مجاني، مفعّل تلقائياً): فهم «جعان»، «منيو»، «اطلب…» + تصحيح أخطاء إملائية آلياً (مثل: منييو → منيو) بدون تعديل يدوي لكل خطأ.

مستوى 2 — ذكاء كامل (مثل ChatGPT): فعّل الخيار أدناه + أدخل مفتاح API من OpenAI أو Groq (مجاني محدود) — عندها يفهم أي صياغة ولهجة ويردّ ليبي أو فصحى.

ليس مطلوباً: Hermes ليس API ذكاء خارجي — الذكاء مدمج هنا. حقل Webhook أدناه للربط مع n8n فقط (اختياري).
