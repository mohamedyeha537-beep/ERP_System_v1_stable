# الإعدادات المرجعية للطباعة الحرارية

نسخة معتمدة تعمل بحجم خط مناسب وفاتورة كاملة (بدون تصغير أو قص).

**معرّف النسخة:** `receipt-print-stable-v4`  
**تاريخ الحفظ:** 2026-02-06

---

## 1. استعادة سريعة (بعد أي تعديل خاطئ)

من مجلد المشروع:

```bat
tools\print_agent\restore-receipt-print.bat
```

ثم:

1. `restart-server.bat`
2. في المتصفح: **Ctrl+F5** عند طباعة فاتورة (لتحميل `receipt_capture.js?v=4`)

---

## 2. التحقق فقط (بدون استعادة)

```bat
python tools\print_agent\verify_receipt_print.py
```

إذا ظهر `OK` فالإعدادات سليمة.

---

## 3. الملفات المحفوظة في `tools/print_agent/reference/`

| ملف | الدور |
|-----|--------|
| `receipt_capture.js` | التقاط الصورة وإرسالها للطابعة |
| `receipt_print.css` | هوامش وحجم الورقة 80mm / 58mm |
| `escpos_raster.py` | تحويل الصورة لأوامر الطابعة |
| `MANIFEST.json` | قائمة الفحوصات والقيم المرجعية |

**ملفات مرتبطة (لا تُنسخ تلقائياً — راجعها يدوياً):**

- `app/templates/_receipt_print_actions.html` — يجب أن يحتوي `receipt_capture.js?v=4`
- `modules/settings/service.py` — `get_paper_css` للورق 80mm: `margin: 3mm`

---

## 4. القيم المهمة (لا تغيّرها دون اختبار)

| الإعداد | القيمة |
|---------|--------|
| عرض الالتقاط 80mm | **302** px (في `thermalCssWidth`) |
| عرض الالتقاط 58mm | **219** px |
| هامش جانبي CSS | **5mm** يمين ويسار |
| ارتفاع إضافي للالتقاط | **+96** px (لإظهار التذييل) |
| نقاط الطابعة 80mm | **576** dot |
| **ممنوع** في `receipt_capture.js` | `centerThermalCanvas` — يسبب تصغيراً شديداً |

---

## 5. الحفظ عبر Git (موصى به)

بعد التأكد من أن الطباعة جيدة:

```bat
git add app/static/receipt_capture.js app/static/receipt_print.css tools/print_agent/
git commit -m "حفظ إعدادات الطباعة الحرارية المعتمدة (v4)"
git tag receipt-print-v4
```

للعودة لاحقاً بـ Git:

```bat
git checkout receipt-print-v4 -- app/static/receipt_capture.js app/static/receipt_print.css tools/print_agent/escpos_raster.py
```

---

## 6. تحديث النسخة المرجعية

عند تحسين الطباعة وتجربتها بنجاح:

1. انسخ الملفات الجديدة إلى `tools/print_agent/reference/`
2. حدّث `MANIFEST.json` (التاريخ، العلامات، رقم `v=` في القالب)
3. شغّل `verify_receipt_print.py` للتأكد

---

## 7. وكيل الطباعة `config.json`

إعدادات الشبكة والطابعات تبقى في `tools/print_agent/config.json` (محلي — لا تُرفع للمستودع إن فيه أسرار).  
احتفظ بنسخة احتياطية يدوية من `config.json` على جهاز الكاشير.
