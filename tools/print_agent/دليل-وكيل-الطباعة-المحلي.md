# دليل وكيل الطباعة المحلي (Local Print Agent)

هذا الملف يشرح خطوة بخطوة كيف تُعدّ الطباعة التلقائية لكل قسم مطبخ عندما يكون **نظام نقطة البيع على سيرفر سحابي** والطابعات داخل شبكة المطعم (`192.168.x.x`).

---

## 1) ما هو «الوكيل»؟

| السؤال | الجواب |
|--------|--------|
| هل هو جهاز؟ | **لا** — هو **برنامج** (ملف Python) |
| أين يعمل؟ | على **كمبيوتر داخل المطعم** (كاشير أو مطبخ) |
| ماذا يفعل؟ | يسحب مهام الطباعة من السيرفر ويطبعها على الطابعات المحلية |
| لماذا نحتاجه؟ | السيرفر السحابي **لا يستطيع** الاتصال مباشرة بـ IP الطابعات الداخلية |

**الملف:** `tools/print_agent/print_agent.py`  
**الإعداد:** `tools/print_agent/config.json` (تنشئه أنت من المثال)

---

## 2) الصورة العامة

```
[سحابة]  السيرفر (POS)  ── إنترنت ──►  [مطعم]  كمبيوتر + برنامج الوكيل  ── LAN ──►  الطابعات
                │                                    │
                │  ينشئ print_jobs                  │  يسحب المهام ويطبع
                └────────────────────────────────────┘
```

يمكن أن يكون **نفس كمبيوتر الكاشير** يشغّل:
- المتصفح (نظام POS)
- برنامج الوكيل (في الخلفية)

---

## 3) المتطلبات قبل البدء

- [ ] Python 3.10+ مثبّت على كمبيوتر المطبخ/الكاشير
- [ ] الطابعات حرارية **ESC/POS** ويفضّل اتصال **شبكة (Ethernet)**
- [ ] الكمبيوتر والطابعات على **نفس شبكة الراوتر** (Wi‑Fi أو كيبل)
- [ ] معرفة **IP كل طابعة** (مثال: `192.168.1.50`) والمنفذ غالباً `9100`
- [ ] السيرفر يعمل ويمكن الوصول له من المطعم (رابط HTTPS أو HTTP)

## الجزء أ — إعداد السيرفر (لوحة الإدارة)

سجّل دخولك كمسؤول وافتح: **`/admin/printing`**

### الخطوة 1: إنشاء وكيل طباعة

1. اذهب إلى: **`/admin/printing/agents`**
2. اكتب اسماً (مثال: `وكيل مطبخ الفرع الرئيسي`)
3. اضغط **«إنشاء + رمز»**
4. **انسخ الرمز فوراً** — يُعرض مرة واحدة فقط  
   (ستضعه لاحقاً في `config.json` تحت `agent_token`)

### الخطوة 2: إضافة الطابعات

1. اذهب إلى: **`/admin/printing/printers`**
2. لكل طابعة أضف:

| الحقل | مثال | ملاحظة |
|-------|------|--------|
| الاسم | طابعة الشواء | |
| الرمز (code) | `GRILL` | فريد، بحروف إنجليزية |
| نوع الاتصال | `local_agent` | إلزامي للوكيل |
| الوكيل المحلي | اختر الوكيل الذي أنشأته | |
| local_printer_key | `grill` | **نفس المفتاح** في `config.json` |
| IP | `192.168.1.50` | اختياري (يُرسل للوكيل في المهمة) |
| المنفذ | `9100` | الافتراضي لمعظم الطابعات |
| عرض الورق | `80` | 58 أو 80 مم |

3. احفظ ثم اضغط **«اختبار طباعة»** — يجب أن تظهر مهمة في **`/admin/printing/jobs`**

### الخطوة 3: أقسام المطبخ

1. اذهب إلى: **`/admin/printing/sections`**
2. أنشئ قسماً لكل منطقة تحضير:

| القسم | الرمز | الطابعة |
|-------|-------|---------|
| شواء | `GRILL` | طابعة GRILL |
| حلويات | `DESSERT` | طابعة DESSERT |

> عند الإرسال للمطبخ: كل قسم يطبع **بنوده فقط** على طابعته.

### الخطوة 4: ربط الأصناف والفئات

**من الفئات** (`/catalog/categories`):  
للفئة الجذر — اختر **«قسم المطبخ (طباعة)»**.

**من الأصناف** (`/catalog/products`):  
- **قسم المطبخ للطباعة** على الصنف → يغلب على قسم الفئة  
- إن تركت الصنف فارغاً → يُستخدم قسم الفئة

**قاعدة التوجيه:**
```
لكل بند في الفاتورة:
  إن وُجد product.kitchen_section_id  → استخدمه
  وإلا category.kitchen_section_id (صعوداً للفئة الأب)
```

## الجزء ب — إعداد الكمبيوتر (ملف config.json)

### الخطوة 5: نسخ ملف الإعداد

على كمبيوتر المطبخ/الكاشير:

```powershell
cd "C:\Users\PIXEL\OneDrive\Desktop\pos\tools\print_agent"
copy config.json.example config.json
notepad config.json
```

### الخطوة 6: تعبئة config.json

```json
{
  "server_url": "https://عنوان-سيرفرك.com",
  "agent_token": "الصق_الرمز_من_لوحة_الإدارة",
  "poll_interval_seconds": 2,
  "printers": {
    "grill": {
      "host": "192.168.1.50",
      "port": 9100
    },
    "dessert": {
      "host": "192.168.1.51",
      "port": 9100
    }
  }
}
```

| المفتاح | الشرح |
|---------|--------|
| `server_url` | رابط موقع POS (بدون `/` في النهاية) |
| `agent_token` | الرمز من `/admin/printing/agents` |
| `poll_interval_seconds` | كل كم ثانية يسأل السيرفر (2 مناسب) |
| `printers` | مفاتيح **يجب أن تطابق** `local_printer_key` في لوحة الطابعات |

**مثال الربط:**

| لوحة الإدارة | config.json |
|--------------|-------------|
| local_printer_key = `grill` | `"grill": { "host": "192.168.1.50" }` |
| local_printer_key = `dessert` | `"dessert": { "host": "192.168.1.51" }` |

### الخطوة 8: ماذا يحدث عند التشغيل؟

كل ~2 ثانية البرنامج:

1. `POST /api/print-agent/heartbeat` — «أنا متصل»
2. `GET /api/print-agent/jobs` — جلب المهام المعلّقة
3. لكل مهمة: `claim` → طباعة على IP:9100 → `printed` أو `failed`

## الجزء د — الاختبار

### اختبار 1: من لوحة الإدارة

1. `/admin/printing/printers` → **اختبار طباعة**
2. `/admin/printing/jobs` → الحالة يجب أن تصبح `printed`
3. إن بقيت `pending` → الوكيل **غير شغّال** أو الرمز خطأ

### اختبار 2: من نقطة البيع

1. أضف أصنافاً مربوطة بأقسام مختلفة
2. أرسل الطلب **للمطبخ**
3. كل قسم يطبع تذكرته على طابعته فقط

### اختبار 3: اتصال الشبكة

من نفس الكمبيوتر:

```powershell
Test-NetConnection 192.168.1.50 -Port 9100
```

`TcpTestSucceeded : True` = الطابعة reachable.

1. اضغط `Win + R` → اكتب `shell:startup`
2. أنشئ ملف `تشغيل-وكيل-الطباعة.bat`:

```bat
@echo off
cd /d "C:\Users\PIXEL\OneDrive\Desktop\pos\tools\print_agent"

```

3. عند كل تشغيل لـ Windows يبدأ الوكيل تلقائياً

### طريقة أفضل لاحقاً

تشغيل كـ **خدمة Windows** (NSSM) — للاستقرار على المدى الطويل.

## استكشاف الأخطاء

| المشكلة | السبب المحتمل | الحل |
|---------|----------------|------|
| المهام `pending` ولا تطبع | الوكيل متوقف | شغّل `python print_agent.py` |
| `401` أو رمز غير صالح | token خطأ | أنشئ وكيلاً جديداً وحدّث config |
| `failed` في المهام | IP خطأ أو طابعة مطفأة | تحقق من IP و`Test-NetConnection` |
| تطبع كل الطلب على طابعة واحدة | أقسام غير مربوطة | راجع `/admin/printing/sections` والأصناف |
| `local_printer_key` لا يطابق | اختلاف الأسماء | نفس الاسم في لوحة الطابعة و config.json |
| السيرفر محلي للتجربة | | `server_url`: `http://127.0.0.1:8011` |

**مهم:** المهام الفاشلة **لا تُحذف** — راجع `/admin/printing/jobs` واضغط **إعادة المحاولة**.

## قائمة تحقق سريعة (Checklist)

```
□ وكيل من /admin/printing/agents + حفظ الرمز
□ طابعات local_agent + local_printer_key
□ أقسام مطبخ + ربط كل قسم بطابعة
□ فئات/أصناف مربوطة بالأقسام
□ config.json على PC المطبخ
□ python print_agent.py يعمل
□ اختبار طباعة = printed
□ إرسال طلب حقيقي للمطبخ = طباعة لكل قسم
```

## ملاحظات مهمة

1. **الوكيل برنامج وليس جهازاً** — لا تشتري hardware باسم «وكيل».
2. **الأفضل للمطبخ:** طابعات شبكة Ethernet، وليس Bluetooth.
3. **جهاز واحد يكفي** إذا الكاشير على نفس شبكة الطابعات.
4. **جهازان** فقط إذا الكاشير بعيد عن شبكة المطبخ (PC مطبخ للوكيل فقط).
