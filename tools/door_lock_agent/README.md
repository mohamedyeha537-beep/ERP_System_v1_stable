# وكيل برمجة بطاقات الأقفال (Door Lock Agent)

يعمل على **جهاز الاستقبال ويندوز** المتصل بمبرمج البطاقات USB، ويستدعي `proRFL.dll` من SDK الشركة.

## التشغيل السريع

1. انسخ من مجلد SDK إلى هذا المجلد (أو اترك المسار الافتراضي):
   - `proRFL.dll`
   - ويفضّل أيضاً: `d12.dll`, `d12c.dll`, `AESDIT.dll` إن طلبها النظام
2. انسخ `config.json.example` إلى `config.json`
3. شغّل:

```bat
python door_lock_agent.py
```

للتجربة بدون جهاز:

```bat
python door_lock_agent.py --mock
```

4. في المنظومة: إعدادات الحجز → أقفال البطاقات:
   - تفعيل البرمجة
   - رقم الفندق CoID (يُقرأ من بطاقة صالحة عبر التطبيق/المثال أو زر قراءة)
   - رابط الوكيل: `http://127.0.0.1:9199`
5. لكل شقة: أدخل **رقم القفل** (8 خانات) من إعداد الشقق
6. من شاشة الحجز (مسكّن): برمجة / مسح / قراءة البطاقة

## ملاحظات

- الوكيل يستمع على `127.0.0.1` فقط افتراضياً (آمن).
- المتصفح على نفس الجهاز يستدعي الوكيل مباشرة (CORS مفعّل).
- إن كان السيرفر على VPS والجهاز محلي: البرمجة تتم من جهاز الاستقبال فقط.
