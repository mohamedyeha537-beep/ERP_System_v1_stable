### **الخطوة 1 — إضافة Endpoint بسيط جداً على FastAPI (~ساعة عمل)**

فريقك يضيف ملف واحد في مسار الـ API:

```python
# pos/api/hermes_views.py
from fastapi import APIRouter, Depends
from sqlalchemy.orm import Session
from datetime import datetime

router = APIRouter(prefix="/api/hermes", tags=["hermes"])

@router.get("/catalog")
def get_catalog(db: Session = Depends(get_db)):
    # جلب المنتجات النشطة فقط مع الفئات
    categories = db.query(Category).all()
    result = []
    for cat in categories:
        products = [
            {
                "id": p.id,
                "name_ar": p.name_ar,
                "sell_price": float(p.sell_price),
                "unit": p.unit,
                "is_active": p.is_active,
                "image_url": f"/static/uploads/products/{p.image}" if p.image else None,
            }
            for p in cat.products if p.is_active
        ]
        if products:
            result.append({"id": cat.id, "name_ar": cat.name_ar, "products": products})
    
    # جلب الحملات النشطة فقط
    campaigns = [
        {
            "id": c.id,
            "name": c.name,
            "message": c.message,
            "starts_at": str(c.starts_at),
            "ends_at": str(c.ends_at),
            "is_active": c.is_active,
        }
        for c in db.query(Campaign).filter(Campaign.is_active == True).all()
    ]
    
    return {
        "store_name": "مطعم ومقهى روف",
        "updated_at": datetime.utcnow().isoformat() + "Z",
        "categories": result,
        "campaigns": campaigns,
    }
```

**بعدها يضيف `/api/hermes/catalog` في `main.py` أو `run.py`.**
ده هيعطيك **مصدر واحد للحقيقة**:
- منتgexe `is_active=0` → مختفي من البوت تلقائيًا.
- حملة منتهية (`ends_at` passed) → هتختفي من تيليجرام.
